```

        ↓

Feature Engineering — fraud indicator variables, threshold features
        ↓
Isolation Forest Model Training — contamination parameter tuning
        ↓
Threshold Optimisation — Precision-Recall curve analysis
        ↓
Fraud Score Assignment + Business Reporting Output
```

#### 📈 Key DAX Measures

```dax
-- Overall Attrition Rate
Attrition Rate = 
DIVIDE(
    CALCULATE(COUNTROWS(Employees), Employees[Attrition] = "Yes"),
    COUNTROWS(Employees),
    0
)

-- Average Tenure by Department
Avg Tenure = AVERAGE(Employees[YearsAtCompany])

-- High Risk Employee Count
High Risk Count = 
CALCULATE(
    COUNTROWS(Employees),
    Employees[JobSatisfaction] <= 2,
    Employees[Attrition] = "No"
)

-- Attrition by Salary Band
Attrition by Salary = 
CALCULATE(
    [Attrition Rate],
    ALLEXCEPT(Employees, Employees[SalarySlab])
)

-- YoY Attrition Trend
Attrition YoY = 
VAR CurrentYear = CALCULATE([Attrition Rate], DATESYTD('Date'[Date]))
VAR PrevYear = CALCULATE([Attrition Rate], SAMEPERIODLASTYEAR('Date'[Date]))
RETURN DIVIDE(CurrentYear - PrevYear, PrevYear, 0)
```

> Real-time traffic sign detection on Chinese road datasets using state-of-the-art YOLOv8 architecture — University of Strathclyde MSc Dissertation 2024

#### 📊 KPIs & Metrics

| Metric | Value |
|--------|-------|
| Model Architecture | YOLOv8 (Ultralytics) with CSPDarknet Backbone |
| Dataset | Chinese Traffic Sign Dataset (custom annotated) |
| Inference Type | Real-time detection on live image feed |
| Evaluation Metrics | mAP@0.5, mAP@0.5:0.95, Precision, Recall, FPS |
| Training Environment | Google Colab (GPU) |
| Transfer Learning | COCO pretrained weights fine-tuned |
| Academic Context | MSc Dissertation — University of Strathclyde UK 2024 |

#### 🎯 Research Problem
Autonomous vehicle systems require robust real-time traffic sign recognition across diverse geographic contexts. Chinese road signage presents unique challenges: complex character sets, diverse sign shapes, varied environmental conditions, and occlusion in real-world scenarios — making it an ideal stress-test for generalised detection models.

#### 🧠 Model Architecture

```
Input Image (Chinese Road Dataset)
        ↓
YOLOv8 Backbone — CSPDarknet53 Feature Extraction
        ↓
Feature Pyramid Network (FPN) — Multi-scale Feature Maps
        ↓
Detection Head — Bounding Box Regression + Class Prediction
        ↓
Non-Maximum Suppression (NMS) — Duplicate Box Removal
        ↓
Real-time Annotated Output + Confidence Scores
```

#### 🔬 Methodology

**Dataset Preparation**
- Curated and manually annotated Chinese traffic sign dataset in YOLO format
- Applied data augmentation: rotation, flipping, brightness variation, mosaic, cutout
- Stratified train / validation / test split for unbiased evaluation

**Training Strategy**
- Transfer learning from COCO pretrained YOLOv8 weights
- Fine-tuned on domain-specific Chinese traffic sign classes
- Learning rate scheduling with cosine annealing
- Early stopping + best model checkpoint saving

**Evaluation**
- Mean Average Precision (mAP@0.5 and mAP@0.5:0.95)
- Per-class Precision-Recall curves
- Inference speed benchmarking (FPS)
- Qualitative analysis on unseen real-world test images

#### ⚙️ Tech Stack
`Python 3.9+` `YOLOv8 (Ultralytics)` `PyTorch` `OpenCV` `pandas` `numpy` `matplotlib` `Google Colab (GPU)` `LabelImg (annotation)`
